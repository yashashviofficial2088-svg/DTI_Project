Noise X – Sound Pollution Detection App

Noise X is an Android application designed to monitor environmental sound levels in real time and help users become aware of noise pollution in their surroundings.

🚀 Overview

The app captures audio using the device microphone, processes it to estimate sound intensity (in decibels), and presents the data through a simple and intuitive dashboard. It aims to promote awareness of unhealthy noise exposure in daily environments.

✨ Features
Real-time sound level detection (dB approximation)
Clean dashboard UI built with Jetpack Compose
User authentication (Login screen implemented)
Visual representation of current noise levels
Threshold-based noise indication (basic)
🛠️ Tech Stack
Kotlin
Jetpack Compose (UI)
Android SDK
AudioRecord API (for sound capture)
MVVM Architecture
